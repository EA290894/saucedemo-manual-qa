\# SauceDemo — Manual QA Testing Project



\## About the Project



This is a personal portfolio project focused on manual testing of the SauceDemo web application.



The purpose of this project is to practice software testing techniques, create test documentation, and gain hands-on experience with manual QA processes.



\*\*Application:\*\* \[SauceDemo](https://www.saucedemo.com/)



\## Scope of Testing



The project covers the following areas:



\* Login and authentication

\* Product catalog and product details

\* Product sorting

\* Shopping cart functionality

\* Checkout form validation

\* Price calculation

\* Order completion

\* Navigation and session behavior



\## Testing Activities



\* Test scenario creation

\* Checklist preparation

\* Test case design and execution

\* Positive and negative testing

\* Equivalence Partitioning (EP)

\* Boundary Value Analysis (BVA)

\* Bug identification and observation recording

\* Test result documentation



\## Test Results



\* Multiple functional checks were completed.

\* No confirmed defects were identified within the tested scenarios.

\* One observation was recorded regarding Zip/Postal Code validation. The application accepted `!!!` and allowed checkout to continue. Since the expected input format was not documented, this observation was not classified as a confirmed defect.
